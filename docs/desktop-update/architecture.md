### Кто за что отвечает

| Компонент | Где | Ответственность |
|---|---|---|
| Контроллер предложения и попытки | Новый общий Haskell-модуль рядом с `environments/DesktopStorage.hs` | Версия, платформа, совместимость форматов, кандидат, один актуальный клик, отображение этапа в доверенном shell. UI передаёт действие; путь или URL пакета определяет доверенный источник метаданных. |
| Остановка локальной работы | Существующие `corpora/Main.hs`, `corpora/host/{HostServer,Service}.hs`, `corpora/work/Execution.hs`, `remote/control/Registry.hs` | Одна атомарная развилка Busy/принять остановку. Закрыть приём задач и активацию детей, учесть принятую очередь, закончить штатный teardown. Прототип передавал две команды; при реализации предпочтительна одна операция под общей защитой. |
| Владелец процессов shell | `environments/macos/Application.hs`, `environments/windows/{Shell,Host,Native}.hs` | Согласовать старт, смену корня и клик. Проверить ответ, успешный exit и пустую группу процессов macOS или Job Object Windows. В Welcome/Recovery без backend дождаться завершения возможного старта и подтвердить отсутствие процессов. |
| Владение установкой | Небольшой общий модуль рядом с контроллером, платформенные примитивы у адаптеров | Ключ по каноническому месту установки. Обычные shell и напрямую запускаемый packaged backend удерживают разделяемое владение. Для замены нужно исключительное. Под ним опубликовать запись о начатом handoff вне заменяемых файлов и корней пользователя. |
| Адаптер macOS | Native shell, Sparkle, [упаковщик](../../build/Package.hs) | Связать клик с конкретным релизом, проверить подписи, пережить выход A, заменить приложение и вернуть контекст. Назначить одного владельца перезапуска. |
| Адаптер Windows | Native shell, [сборщик](../../environments/windows/build.ps1), [Inno Setup](../../build/package/windows-installer.iss) | Приватное размещение EXE, проверка точных байтов и издателя перед запуском, подтверждение владельца каталога, отдельные исходы success/failure/reboot, единственный перезапуск. Удалять только явно выбывшие файлы прежней поставки. |

**Передача владения.** Пока backend останавливается, установка ещё занята A. Если переход к исключительному владению проигран другой живой сессии, пакет не запрашивается, A может снова открыть исходный workspace. До первого запроса за пакетом публикуется целевая версия и идентификатор попытки. Каждый вход в установленное приложение проверяет эту запись под той же защитой до доступа к Data Root. Она переживает выход shell. Снимает её владелец после подтверждённой установки или доказанного отказа до замены. Возраст записи, исчезновение PID и одна строка версии недостаточны для решения об успехе. Контекст первого корня и конфигурации передаётся приватно, с областью доступа пользователя.

**Границы первой поставки.** На macOS сначала квалифицируем пользовательскую установку. Для общей копии в /Applications требуется исключение между пользователями; пока оно не доказано, приложение предлагает ручную установку. На Windows отдельно проверяем режим обычного пользователя. Архитектура сохраняет штатную работу нескольких Data Root до обновления. Предложение со сменой формата данных требует отдельной спецификации.

### Сколько кода ожидаем к завершению

Оценка в новых непустых продукционных строках относительно `666a028`. Учитываются Haskell, native binding, UI, изменения установщика и скрипты поставки. Перенос неизменённого кода, генерация, SDK, тесты, логи и документация считаются отдельно. Все числа ниже — оценка финального diff, а не остаток поверх прототипа.

| Работа после переиспользования | Нижняя | Рабочая | Верхняя |
|---|---:|---:|---:|
| Контроллер, предложение, клик, bootstrap и сообщения | 45 | 75 | 110 |
| Допуск работы, остановка, проверка потомков и владение установкой | 120 | 195 | 300 |
| macOS, интеграция Sparkle и перезапуск | 80 | 130 | 215 |
| Windows, доверие к пакету, запуск Inno и исходы | 115 | 180 | 280 |
| Упаковка, подписи и публикация предложения | 50 | 85 | 140 |
| **Доставка и handoff** | **410** | **665** | **1 045** |
| Проверка совместимости объявленных форматов без записи в данные | 25 | 45 | 65 |
| **Полная первая поставка** | **435** | **710** | **1 110** |

Основание — пофункциональная оценка арбитража D2 на релизе и фактически выполненный diff `git diff --numstat 666a028 ba3342d`. Измерение прототипа дало **329 добавленных физических строк вне spec/**, включая CPP, объявления, пустые строки и комментарии: backend/registry 68, общая часть и Cabal 84, macOS 72, Windows 105. Удалено 18 строк. Ещё 533 добавленные строки ушли в исполняемые сценарии стенда и тесты, включая внешние помощники. В собранном прототипе были готовы нативный клик, остановка, скачивание, замена и перезапуск. Оставшаяся неопределённость сосредоточена в продуктовой поставке помощника, разделяемом владении, проверке издателя и восстановлении неоднозначного исхода. Автоматически вычитать 329 из 710 нельзя из-за разного способа счёта и тестовых упрощений.

**Когда уточняем число.** После шагов 3–5 измеряем фактический diff по этим же строкам таблицы и пересчитываем остаток. Перед финальной приёмкой публикуем фактический объём продукта, тестов и сборочного стенда раздельно. Верхняя оценка актуальна, если потребуется отдельная native-обвязка Sparkle или расширение Windows-помощника для восстановления. Полноценная поддержка общей macOS-установки и миграции потребуют отдельной оценки.
